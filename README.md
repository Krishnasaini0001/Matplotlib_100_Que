# 📊 Matplotlib – 100 Questions Practice

Welcome to my **Matplotlib Practice Repository** 🚀

This repository contains **100 practice questions and solutions** designed to build a strong understanding of **Matplotlib**, one of the most important Python libraries for data visualization.

The main goal of this repository is to learn Matplotlib **step-by-step through practical coding questions**.

---

## 🎯 Objective

The purpose of this repository is to:

- Learn Matplotlib from basics to advanced concepts
- Practice data visualization using Python
- Understand different types of plots
- Learn how to customize graphs
- Improve Python data visualization skills
- Build a strong foundation for Data Science and Machine Learning
